# COMP8240 Min-K% Prob Replication

This repository contains materials for my COMP8240 Applications of Data Science project at Macquarie University.

The project replicates and extends:

Shi et al. (2024), "Detecting Pretraining Data from Large Language Models", ICLR 2024.

## Project stages

1. Reproduce selected Min-K% Prob results on WikiMIA.
2. Evaluate the method on additional existing datasets.
3. Construct new datasets to investigate temporal and distribution-shift effects.
4. Compare Min-K% Prob with blind baselines and evaluate possible dataset confounding.

## Status

Project proposal and preliminary feasibility testing.
